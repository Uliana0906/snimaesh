# Снимаешь? 🏠💸

Игра: тебе показывают фото квартир в Суздале, а ты угадываешь цену за ночь бегунком.
10 реальных, активных объявлений с Авито. В финале — честный вердикт:
**Чмошник** 🥲, **Красава** 😎 или **Держишь район!** 💸

## Правила
1. Листай галерею фото квартиры (свайп), смотри адрес и рейтинг.
2. Двигай бегунок — предлагай свою цену за ночь (от 1 000 до 20 000 ₽).
3. Жми «Предложить цену» — увидишь реальную цену, разницу в ₽ и %, баллы
   и ссылку на живое объявление на Авито.
4. После 10 квартир — итоговый вердикт по тому, куда ты в основном промахивался.

## Баллы (чем ближе к реальной цене — тем жирнее)
| Ошибка | Баллы |
|---|---|
| ≤ 5%   | 100 (в стоку!) |
| ≤ 10%  | 75 |
| ≤ 20%  | 50 |
| ≤ 35%  | 30 |
| ≤ 50%  | 15 |
| > 50%  | 0 |

Максимум за игру — **1000 баллов**. «Угадал» считается ошибка ≤ 10%.
Итоговый вердикт:
- **Чмошник** — чаще всего называл цены ниже реальных;
- **Красава** — чаще всего попадал в цену (±10%);
- **Держишь район!** — чаще всего называл цены выше реальных.

## Публикация на GitHub Pages
1. Создай репозиторий на GitHub (например, `snimaesh`).
2. Загрузи в корень: `index.html`, `data.js`, папку `img/` (README не обязателен).
3. Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты игра доступна по адресу `https://<твой-логин>.github.io/snimaesh/`.

Никакой сборки и зависимостей — чистый статический HTML/JS, всё влезает в один репозиторий.

## Данные
- Источник: выгрузка **активных** объявлений посуточной аренды квартир в Суздале с Авито
  (57 активных лотов, для игры отобраны 10 с фотографиями; порядок в раунде перемешивается).
- Фото скачаны с CDN Авито и оптимизированы (до 900 px, JPEG, ~8 КБ на фото,
  всего ~400 КБ на 50 фото) — открываются даже на слабом мобильном интернете.
- Ссылка в результатах каждого лота ведёт на оригинальное объявление.

## Структура
```
index.html   — вся игра (HTML + CSS + JS, мобильная версия в приоритете)
data.js      — 10 лотов: цена, адрес, рейтинг, отзывы, ссылка на Авито, фото
img/         — 50 оптимизированных фотографий
```
